# История изменений

## 1.2.0 — 2026-10-16

- `multiplier` можно задать графиком по датам: `[{value: 4.84}, {since: "2026-10-01", value: 5.38}]` —
  например, стоимость электроэнергии при смене тарифа считается по тарифу своего периода.

## 1.1.2 — 2026-10-13

- Светлая тема: линии, полосы строк, приглушённые столбцы, итоги, подсветка отклонений и выделение
  теперь берут цвета от темы HA — таблица одинаково читается в тёмной и светлой теме.
- Демо-страница: `docs/demo.html?theme=light`.

## 1.1.1 — 2026-10-13

- Исправлено: после того как Home Assistant переставлял карточку на странице, не работали Esc и Ctrl+C,
  а протягивание выделения не заканчивалось при отпускании кнопки мыши.

## 1.1.0 — 2026-10-13

- Выделение ячеек как в Excel: клик, протягивание, Shift+клик (диапазон), Ctrl+клик (добавить/убрать),
  клик по заголовку — весь столбец, по дате — вся строка; на сенсорных экранах — касания.
- Строка под таблицей: количество, сумма, среднее, минимум, максимум выделенного;
  при разных единицах — по каждому столбцу отдельно.
- Копирование выделенного для вставки в Excel (Ctrl+C или кнопка «Копировать»), Esc — снять выделение.
- Параметр `selection: false` выключает выделение.

## 1.0.0 — 2026-10-06

Первый публичный релиз.

- `period: week` и `period: month`: начало запроса выравнивается на понедельник / 1-е число,
  `prefer` корректно определяет завершённость недели или месяца.
- `getStubConfig`: при добавлении карточки через UI подставляется подходящий сенсор.
- Ссылка на документацию в списке карточек; `ha-card` явно блочный.
- Тесты (`node --test`), демо-страница без Home Assistant, примеры конфигураций.

## 0.6.1

- `avg_nonzero` возвращает `0`, если данные есть, но все нулевые; прочерк — только при отсутствии данных.

## 0.6.0

- Подсветка отклонений: правила `below` / `above` / `equals` / `empty`, уровни `warn` / `bad` / `good`,
  отметка строки (`row`), подсказка при наведении, легенда под таблицей, сохранение цветов при печати.

## 0.5.0

- Встроенный выбор периода: поля дат, стрелки сдвига, быстрые периоды (`presets`),
  запоминание в браузере (`storage_key`), ссылки `?from=&to=`. `input_datetime` больше не обязательны.

## 0.4.0

- `prefer` — точный источник для завершённых интервалов начиная с `prefer_since`.

## 0.3.x

- `source_period` для любой таблицы (в т.ч. 5minute → hour), `fallback_stat`.
- Сетка часов для `period: hour` (включая текущий час), несколько строк итогов (`footers`).
- Время загрузки и версия скрыты по умолчанию (`show_debug`).
- Вертикальные разделители столбцов (`column_borders`).

## 0.2.0

- Агрегация суток из часовой статистики (`source_period: hour`, `agg`), группы столбцов,
  сводные строки (`summary`), `date_format`, `footer_labels`, `footer_title`, `font_size`.

## 0.1.0

- Первая версия: таблица по суткам из `recorder/statistics_during_period`, итоги, CSV.
